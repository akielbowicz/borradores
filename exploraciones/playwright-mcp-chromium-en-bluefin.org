#+title: Playwright MCP + Chromium en Bluefin (Fedora Atomic)
#+date: 2026-03-19

* Problema

El Playwright MCP server en Amp falla con:

#+begin_example
browserType.launchPersistentContext: Chromium distribution 'chrome' is not found at /opt/google/chrome/chrome
Run "npx playwright install chrome"
#+end_example

* Causa raíz

En Bluefin/Silverblue, Chrome/Chromium está instalado como Flatpak (~org.chromium.Chromium~), no como paquete nativo. Playwright por defecto busca el canal =chrome= en =/opt/google/chrome/chrome=, que no existe.

Sin embargo, Playwright ya tiene browsers bundled instalados en =~/.cache/ms-playwright/=:

#+begin_example
~/.cache/ms-playwright/chromium-1212/chrome-linux64/chrome
#+end_example

El problema es que la config MCP no le dice que use =chromium= (bundled) en vez de =chrome= (sistema).

* No hace falta distrobox

El Chromium bundled de Playwright corre nativo en Fedora Atomic sin problemas. Verificado:

#+begin_src bash
~/.cache/ms-playwright/chromium-1212/chrome-linux64/chrome --headless --no-sandbox --dump-dom about:blank
# → <html><head></head><body></body></html>
#+end_src

No necesitás instalar Chrome/Chromium vía distrobox, rpm-ostree, ni Flatpak para esto. Playwright trae su propio binario con todas las dependencias.

* Solución para Amp

Agregar =--browser chromium= a los args del MCP server en =~/.config/amp/settings.json=:

#+begin_src json
"amp.mcpServers": {
  "playwright": {
    "command": "npx",
    "args": [
      "@playwright/mcp@latest",
      "--browser",
      "chromium"
    ]
  }
}
#+end_src

Reiniciar Amp después del cambio.

* Solución para Claude Code

** El plugin ignora =.mcp.json=

Claude Code tiene un plugin oficial de Playwright (=playwright@claude-plugins-official=). El plugin define un =.mcp.json= en:

#+begin_example
~/.claude/plugins/marketplaces/claude-plugins-official/external_plugins/playwright/.mcp.json
#+end_example

Pero Claude Code *ignora los args del =.mcp.json= del plugin*. Siempre lanza:

#+begin_example
npm exec @playwright/mcp@latest --headless
#+end_example

Sin =--browser chromium=, sin =--executable-path=, sin =env=. Editar ese =.mcp.json= no tiene efecto.

Tampoco funciona:
- =pluginConfigs= en =settings.json= (no pasa args al proceso)
- =env.CHROME_PATH= en =settings.json= (Playwright no lee esa variable)

** Solución: symlink

La solución más simple es crear un symlink donde Playwright busca Chrome:

#+begin_src bash
sudo mkdir -p /opt/google/chrome
sudo ln -s ~/.cache/ms-playwright/chromium-1212/chrome-linux64/chrome /opt/google/chrome/chrome
#+end_src

Esto hace que el canal =chrome= (el default) encuentre el Chromium bundled de Playwright. No requiere cambios de config.

*Nota*: cuando Playwright se actualiza y cambia la versión del browser (ej: =chromium-1212= → =chromium-1220=), hay que actualizar el symlink.

** Alternativa: =claude mcp add=

Si no querés el symlink, podés agregar el MCP server manualmente con =--browser chromium=:

#+begin_src bash
claude mcp add --transport stdio playwright --scope user -- npx -y @playwright/mcp@latest --browser chromium --headless
#+end_src

Esto agrega a =~/.claude.json= y bypasea el plugin. Verificar con =claude mcp list=.

** Nota sobre =--headless=

Claude Code no tiene GUI, así que =--headless= es necesario. Amp sí puede abrir ventana de browser, así que ahí es opcional.

** Otros comandos útiles

#+begin_src bash
claude mcp list               # ver servers y estado
claude mcp remove playwright  # quitar si hace falta
#+end_src

* Browsers instalados

#+begin_example
~/.cache/ms-playwright/
├── chromium-1212/           ← este es el que usa Playwright MCP
├── chromium_headless_shell-1212/
├── ffmpeg-1011/
├── mcp-chrome/              ← user data dir (perfil) del MCP con canal chrome
└── mcp-chromium/            ← user data dir (perfil) del MCP con canal chromium
#+end_example

=npx playwright install --dry-run= muestra qué versiones están disponibles (chromium, firefox, webkit).

* Notas

- =chrome= = Google Chrome del sistema (requiere instalación nativa, NO existe en Bluefin)
- =chromium= = browser bundled por Playwright en =~/.cache/ms-playwright/=
- En sistemas con Flatpak (Bluefin, Silverblue), siempre usar =chromium= o =--headless=
- No hace falta distrobox ni rpm-ostree para esto
